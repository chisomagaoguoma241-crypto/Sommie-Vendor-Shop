A clear premise.

The rules for using this customer-website demonstration.

Important

This is a static, browser-only demonstration rather than an operating store.

Use of this prototype

The website is supplied as a frontend interface demonstration. Product listings, stock figures, delivery descriptions, account features, and checkout flows are interface examples and should not be read as a commercial offer.

No sales or payments

Submitting the checkout flow does not place an order, transfer payment information, reserve inventory, or create a legal agreement for the purchase of goods.

Local account demonstration

Accounts created through the interface are stored only in browser local storage and do not constitute an authenticated account on a merchant system.

Availability

Because the project is client-side only, features depend on the availability of the browser and any external visual resources being used. Functionality may reset when browser data is removed.
